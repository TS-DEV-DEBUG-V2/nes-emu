## Overview

`nes-emu` is a lightweight NES emulator focused on simplicity, accuracy, and portability.

The project is written entirely in pure C with no unnecessary abstractions or bloated dependencies.

Main goals:

- Accurate emulation
- Clean codebase
- Fast execution
- Portable architecture
- Web support

---

## Features

- Pure C implementation
- Lightweight and minimal
- Web version support
- Cycle-accurate PPU
- Cycle-accurate APU
- Correct NES color palette
- Support for important mappers
- Portable codebase
- No external engine dependency
- Focused on accuracy and readability

- Simple
- Readable
- Fast
- Accurate
- Minimal

No unnecessary frameworks.
No bloated architecture.
Just a clean emulator written in C.
